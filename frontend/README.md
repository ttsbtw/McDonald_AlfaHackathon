# Frontend кредитного кабинета

React + Vite интерфейс клиентского и сотруднического кабинетов. Оба кабинета
работают с фактическим API заявок, проверок, скоринга, underwriting и аудита.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+. После установки зафиксированных зависимостей:

```sh
npm install
npm run dev
```

Vite слушает `http://localhost:5173` и проксирует `/api` на
`http://localhost:8000`. Другой адрес API задаётся через `VITE_API_URL`.

Для общего запуска из корня репозитория используйте `docker compose up --build`.
Production-сборку раздаёт Nginx на `http://localhost:5173`, запросы `/api`
проксируются во внутренний контейнер backend.

## Проверки

```sh
npm test
npm run build
```

Тесты без браузера проверяют подбор продукта, полноту анкеты и преобразование
денежных значений в десятичные строки backend-контракта.

## Реализованные сценарии

- вход клиента и сотрудника по подготовленным логину и паролю;
- автоматическое направление в кабинет по роли из `/auth/me`;
- получение компании, продуктов и собственных заявок;
- подбор продукта по цели, сумме и сроку с объяснением;
- создание, редактирование и повторное открытие черновика;
- клиентская проверка полноты анкеты, согласие на запрос БКИ и расчёт платежа перед отправкой;
- актуальный статус, история заявки, уточнение анкеты и альтернативные условия;
- очередь и карточка сотрудника с отдельными скорингом, предварительным и итоговым решением;
- результаты БКИ, Compliance и underwriting с объяснениями на русском языке;
- ручной разбор Compliance и выгрузка журнала аудита в JSON/CSV;
- блокировка недопустимого одобрения и действий по закрытой заявке;
- явные состояния загрузки, пустого результата, ошибок и сохранения.
