# Умный кредитный кабинет предпринимателя

Проект команды **McDonald** для хакатона **«Альфа-Будущее 2026»**.

Цифровой кредитный кабинет для малого и микробизнеса, объединяющий подачу заявки предпринимателем и её рассмотрение сотрудником банка в одном веб-приложении.

## О проекте

Предпринимателю важно понимать, какой продукт выбрать, какие сведения предоставить и что происходит с заявкой после отправки. Сотруднику банка нужны данные о бизнесе, результаты проверок и основания для принятия решения.

Наш проект связывает эти задачи в единый процесс с сохранением данных, последовательными состояниями заявки и объяснимой оценкой кредитного риска.

## Основной сценарий

1. **Выбор продукта.** Предприниматель указывает цель, сумму и срок финансирования.

2. **Подготовка заявки.** Заполняет сведения о компании и финансовых показателях бизнеса.

3. **Автоматические проверки.** Система проверяет данные и получает информацию из локальных симуляторов внешних источников.

4. **Скоринговая оценка.** Рассчитывается балл и формируется предварительная рекомендация с объяснением.

5. **Рассмотрение сотрудником.** Сотрудник банка принимает решение или запрашивает уточнения.

6. **Получение результата.** Предприниматель видит статус, решение и дальнейшие действия в кабинете.

## Архитектурный подход

Приложение строится как модульный монолит: веб-интерфейс взаимодействует с backend API, а backend управляет заявками, хранением данных, проверками и вызовом скоринга.

Модуль скоринга отделён от API и базы данных, чтобы его можно было независимо тестировать и развивать.

## Принципы решения

- **Прозрачность:** клиент понимает состояние заявки и необходимые действия.

- **Объяснимость:** оценка сопровождается факторами и причинами рекомендации.

- **Разделение ответственности:** скоринг оценивает риск, итоговое решение принимает сотрудник.

- **Автономность:** основной сценарий не зависит от платных API и корпоративных систем банка.

- **Воспроизводимость:** внешние интеграции моделируются локально, демонстрационные данные синтетические.

- **Простота:** архитектура ограничена задачами MVP и возможностями небольшой команды.

## Границы прототипа

Проект предназначен для демонстрации кредитного процесса. Условия продуктов и правила оценки являются демонстрационными и не представляют реальную кредитную политику Альфа-Банка.

Реальная выдача денежных средств и юридически значимое подписание документов находятся за границами MVP.
